# 做法层设计：CSP 三层法

> 原访谈最大的缺口是「做法」——只给了方向，没给做法。
> 本文件补齐这一段。原则：**给结构，不给套路。结构服务于发心，不是发心服务于结构。**

---

## 一、CSP 三层法

| 层 | 回答什么 | 产出 |
|---|---|---|
| **C 内容层（Content）** | 讲什么 | 12 条选题库 |
| **S 结构层（Structure）** | 怎么讲 | 一条视频的骨架 |
| **P 生产层（Production）** | 怎么拍、怎么发 | 30 天排期 + 一鱼多吃 SOP |

---

## 二、C 内容层：选题从哪来

### 2.1 核心方法：自问自答

**让对方列出"客户会问、但客户问不出口"的问题。**

> 「你会自问自答的第一个问题是什么？」

源访谈的真实产出：
- 什么是创新教育？
- 什么是 PBL？为什么要做 PBL？怎么做 PBL？
- 什么是 AI？为什么要学 AI？
- 你教的 AI 跟市面上的有什么不一样？

**判断标准**：一个好问题 = 客户心里有、但嘴上问不出来的那个。

### 2.2 选题的四个来源

| 来源 | 提问 | 例 |
|---|---|---|
| **自问自答** | 客户最常误解你什么？ | "用 AI 提分？那是把路走窄了" |
| **案例库** | 讲一个具体的人的故事 | 那个做了二次元平台的初一男孩 |
| **观点库** | 你最不能忍行业哪种做法？ | 市面 AI 课在利用贪嗔痴 |
| **反常识** | 大家都这么认为，但你觉得是错的 | 十岁前不要学逻辑 |

### 2.3 选题库模板（12 条）

| # | 选题 | 来源 | 讲给谁 | 一句话核心 |
|---|---|---|---|---|
| 1 | | 自问 | | |
| 2 | | 案例 | | |
| ... | | | | |
| 12 | | 观点 | | |

**要求：12 条里至少 4 条是案例（有具体的人），至少 3 条是反常识。**

## 三、S 结构层：一条视频的骨架

### 3.1 立场：要结构，不要套路

源访谈访谈者明确鄙视"黄金三秒、钩子、怎么获客"。**这个立场是对的**——但不能用"反套路"当借口不给结构。

**裁决：**
- ❌ 不给：制造焦虑的钩子、凭空设计的人设、与发心无关的流量技巧
- ✅ 要给：让真实内容被听懂的结构

### 3.2 通用骨架（60-180 秒）

```
① 开口（10 秒）：说一个具体的「人」
   不要自我介绍，直接进场景
   例：「有个初一的孩子，整个暑假都泡在我这儿。」

② 张力（20 秒）：他遇到了什么困境
   —— 这一段决定别人要不要继续听

③ 转折（30 秒）：发生了什么，让他不一样了
   —— 这里是你的方法真正出场的地方

④ 提炼（20 秒）：这件事说明了什么
   —— 从个案上升到观点

⑤ 收口（10 秒）：回到发心，一句话
   不要喊关注，说你真正相信的那句
```

### 3.3 三种开拍形式（按恐惧程度选）

| 形式 | 适合 | 上手难度 |
|---|---|---|
| **对谈式**（找人问你） | 不敢对着镜头讲、一讲就僵 | ⭐ 最低 |
| **口播式**（对着镜头讲） | 表达能力强 | ⭐⭐⭐ |
| **记录式**（拍工作过程 + 旁白） | 有真实场景可拍 | ⭐⭐ |

**如果对方有"不敢"，直接选对谈式。先发出去，再优化形式。**

### 3.4 置顶视频三条（必须设计）

置顶视频 = 陌生人 3 秒内决定关不关注你。三条按这个顺序：

| 条 | 内容 | 禁忌 |
|---|---|---|
| 第 1 条 | **我是谁 + 我为什么做这件事**（叙事主线） | ❌ 履历堆砌、数据炫耀 |
| 第 2 条 | **我最核心的一个观点**（反常识） | ❌ 面面俱到 |
| 第 3 条 | **一个具体的人的改变**（案例） | ❌ 抽象说教 |

## 四、P 生产层：排期与分发

### 4.1 节奏：要真实数字，不要理想化

**必问一题**：
> 「**一周你能稳定产出几条？**」

追问（防虚报）：
> 「按你最忙的那一周算，能保证几条？」
> 「如果只能保证一条，那一条定在星期几？」

**裁决：宁可一周一条稳定发一年，不要一天一条发两周就断。**

### 4.2 团队与工具

| 角色 | 什么时候需要 | 验收标准 |
|---|---|---|
| 拍剪 | 周更 3 条以上 | **把访谈对话丢给他，问他：你懂我的发心吗？不懂就剪不了** |
| IP 助理 | 需要选题支持时 | 看他能不能替你提出好问题 |
| 分发 | 多平台时 | 纯体力活，可外包 |

### 4.3 一鱼多吃 SOP

```
一次表达（直播 / 访谈 / 对谈）
   ↓
原始素材（录音 + 逐字稿）
   ↓  AI 捞金句
① 金句卡片（图文）
② 短视频切片（3-5 条）
③ 长文（公众号 / 小红书）
④ 音频（播客）
⑤ 内容素材库（未来选题）
```

**核心公式：直播即获客，直播即素材，素材即内容，内容即销售。**

### 4.4 30 天排期模板

| 周 | 动作 | 产出 | 验收 |
|---|---|---|---|
| 第 1 周 | 拍第一条（对谈式） | 1 条视频 | 发给教练 |
| 第 2 周 | 拍第二条 + 第一条复盘 | 2 条 | 看完播/反馈 |
| 第 3 周 | 拍置顶视频第 1 条 | 1 条（置顶） | 定稿 |
| 第 4 周 | 稳定节奏 + 第一次直播/对谈 | 4 条 + 1 场 | 复盘 |

## 五、做法层的 8 个关键提问

1. 你会自问自答的第一个问题是什么？
2. 除了这个，还能自问出哪五个问题？
3. **第一条视频你打算讲什么？**（追问：讲给谁、解决他什么困惑、结尾留一句什么话）
4. 这条多长？在哪拍？对着镜头还是找人对谈？
5. **一周你能稳定产出几条？**（按最忙那周算）
6. **谁来拍、谁来剪？**（验收：他懂不懂你的发心）
7. 一次内容怎么多处用？
8. 你的客户主要在哪儿？你打算主攻哪个平台？

## 六、常见错误

| 错误 | 后果 | 正解 |
|---|---|---|
| 只给方向不给做法 | 认知不落地，两周蒸发 | 必须有排期和第一条主题 |
| 给套路不给结构 | 内容与发心脱节，做不下去 | 结构服务于发心 |
| 节奏理想化（日更） | 两周断更，产生挫败 | 按最忙那周定节奏 |
| 先买设备再开始 | 拖延 | 手机先拍第一条 |
| 想清楚所有选题再开拍 | 永远开不了头 | 先拍一条，再迭代 |
| 多平台同时铺开 | 精力分散，全平台半死不活 | 先主攻一个平台 |
