# 交付物模板

> 流程走完后，按此模板输出完整交付物。
> 原则：**所有核心句子必须是对方自己说过的原话**，教练只负责整理和命名。

---

## 交付清单（10 项）

```
□ 1.  一句话叙事（他自己的话）
□ 2.  一个公式
□ 3.  一条生命周期路径
□ 4.  内容选题库（12 条）
□ 5.  第一条视频：主题 + 结构 + 时长
□ 6.  30 天做法排期
□ 7.  不做什么清单
□ 8.  升级版发心（一句话）
□ 9.  30 天行动契约
□ 10. 未解决问题清单（诚实版）
```

---

## 1. 一句话叙事

**格式**：什么时间 → 遇到什么 → 产生什么念头 → 走到今天

**要求**：
- 必须是他自己的原话拼接，不是你帮他写的
- 不含履历数据（那是秀肌肉）
- 读出来不超过 30 秒

**例**：
> 「我是国内最早做项目制教学的那批人。我一直信一句话：教不好孩子等于偷钱抢钱。后来去了互联网公司，没人再跟我谈初心，我很难受。直到 AI 来了——我觉得我等的东西终于来了。所以 2023 年我出来创业。」

---

## 2. 一个公式

**格式**：`〔领域〕 = 〔要素1〕 + 〔要素2〕 + 〔要素3〕`

**要求**：
- 每个要素必须是**十年后还成立的词**，不能是动作
- 要素数量 3-4 个，超过 4 个记不住
- 每个要素要能解释"它在这里承担什么作用"

**例**：
> AI 时代的家庭教育 = 孩子 + PBL + AI + 被看见

| 要素 | 承担什么作用 |
|---|---|
| 孩子 | 主体，一切从他的问题出发 |
| PBL | 方法，不只是用来学 AI |
| AI | 工具，把孩子的世界变大 |
| 被看见 | 目的，AI 时代唯一确定的事 |

---

## 3. 一条生命周期路径

**格式**：`阶段1 → 阶段2 → 阶段3 → 阶段4 → 阶段5`

**要求**：每个阶段标注「客户处于什么状态」+「可见产出」

**例**：

| 阶段 | 客户状态 | 可见产出 |
|---|---|---|
| 1. Demo 项目 | 什么都不会 | 一个网站 |
| 2. 接付费小商单 | 知道自己能创造 | 一个小程序 |
| 3. 找到热爱 | 开始有想法 | 自己的项目 |
| 4. 参赛/商单放大 | 有了作品集 | 奖项、收入 |
| 5. 被看见 | 找到自己的路 | 对外分享 |

## 8. 升级版发心（一句话）

**要求**：从"我要影响我的客户"升级到"我要影响更多人"。

**例**：
> 「你自己先要影响千千万的家长，你的孩子才能学你去影响千千万的孩子。」

## 9. 30 天行动契约

| 项目 | 内容 |
|---|---|
| **一件最重要的事** | |
| **为什么是它** | （其他所有事的前提） |
| **意愿分数（1-10）** | （<7 分不许签署，回头处理障碍） |
| **第一次动作** | 具体日期 + 星期 |
| **频率** | |
| **验收标准** | 做完怎么算完成 |
| **验收人** | 谁看 |
| **障碍预案** | 什么会让它失败；第 5 天没动说明什么；怎么办 |

**承诺复述**（必须让他自己说一遍）：
> 「用你自己的话，把接下来 30 天你要做的事说一遍。」
