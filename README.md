# 教练式 IP 访谈 · IP Coaching Interview

> 一个给 AI 助手用的技能包（Skill）。通过**一问一答、层层递进**的教练对话，帮一个「有干货但讲不清楚 / 想做但启动不了」的人，理清做 IP 的**方向**与**做法**，同时破除心理障碍。

---

## 它解决什么问题

很多人做不起个人品牌，卡的不是能力，而是三件事：

1. **讲不清楚** —— 有经验、有成果、有客户，但让他说"你是做什么的"，他只能背一段谁都听不懂的话术。
2. **启动不了** —— 方向似乎懂了，但第一条内容永远拍不出来。
3. **心里过不去** —— 觉得"做 IP = 卖课 = 割韭菜"，道德上不允许自己去做。

市面上的内容大多只教第三层的一半（流量技巧），前两层没人管，第三层更没人碰。**这个技能包把三层一起解决。**

---

## 核心设计

### 一、严格一问一答

不是一次性甩给你一份问卷，而是：

- 每次**只问一个问题**，问完就停，等你回答
- 收到回答后走三步：**接住 → 深挖 → 递进**
- 每进一层标注进度：`【第 2 层 / 共 5 层 · 资源与高峰】`

这样设计的理由：**答案必须是你自己说出来的才算数。** 别人替你说的，你不会执行。

### 二、双轨结构：明线走流程，暗线破心障

| | 明线（内容） | 暗线（心理） |
|---|---|---|
| 目标 | 理清方向 + 设计做法 | 破除心理障碍 |
| 判据 | 拿到交付物 | 从"我做不到"变成"我可以" |

**暗线的四道关卡**（全程随时触发）：

| 关卡 | 典型信号 | 破法 |
|---|---|---|
| **不配** | "我没什么特别的" | 借他人视角 + 例外提问 |
| **不敢** | "怕被骂""怕熟人看见" | 恐惧拆解 + 最小暴露实验 |
| **不愿** | "做 IP 就是割韭菜" | **四把锁拆除**（最难也最关键） |
| **不会** | "我不知道怎么拍" | 落到最小可行动作 |

> **铁律：`不愿`这一关不解，后面所有做法都不会被执行。**

### 三、五层九步流程

```
【第 0 步】合约        → 今天什么算成功
【第 1 层】定位此刻    → 刻度化：几分？为什么不是更低？
【第 2 层】资源与高峰  → 哪个瞬间"就是它了"
【第 3 层】信念与身份  → 你信什么 / 你是谁 / 你在等什么
   ├─ 命名 ①：叙事主线
【第 4 层】业务澄清    → 假设我是客户，我付钱后会经历什么
【第 5 层】创造定型    → 奇迹问题 + 公式 + 做法设计（CSP 三层法）
   ├─ 命名 ②：定型 + 意义升维（你不打这个样，谁打这个样）
【第 6 步】承诺落地    → 30 天行动契约
```

**设计原则：不许跳层。** 方向没通就给做法，是无根之木。

### 四、做法层：CSP 三层法

原版访谈最大的缺口是"只给方向不给做法"，本技能补齐：

| 层 | 回答什么 | 产出 |
|---|---|---|
| **C** 内容层 | 讲什么 | 12 条选题库（来自自问自答） |
| **S** 结构层 | 怎么讲 | 一条视频的骨架 |
| **P** 生产层 | 怎么拍、怎么发 | 30 天排期 + 一鱼多吃 SOP |

立场是**给结构，不给套路**：不要制造焦虑的钩子，但给让真实内容被听懂的结构。

## 交付物

流程走完，你会拿到 10 项：

1. 一句话叙事（用你自己的话）
2. 一个公式（例：AI 时代的家庭教育 = 孩子 + PBL + AI + 被看见）
3. 一条生命周期路径
4. 内容选题库（12 条）
5. 第一条视频：主题 + 结构 + 时长
6. 30 天做法排期
7. 不做什么清单
8. 升级版发心（一句话）
9. 30 天行动契约（做什么 / 几号 / 怎么验收 / 卡了怎么办）
10. 未解决问题清单（诚实版 —— 不许写"无"）

## 用法

### 触发

直接说：

- 「帮我梳理一下做 IP 的方向」
- 「我有干货但讲不出来」
- 「用教练式访谈跟我聊聊个人品牌」
- 「做自媒体不知道拍什么」

### 三种时长

| 版本 | 时长 | 问题数 | 适合 |
|---|---|---|---|
| **完整版** | 90-100 分钟 | 约 40 个 | 第一次系统梳理 |
| **标准版** | 45 分钟 | 约 20 个 | 有基础，补主线 |
| **急救版** | 15 分钟 | 5 个 | 只求破局 |

**无论多短，两次命名和一次承诺不能省。**

### 15 分钟急救版（5 问）

1. 今天结束时，发生了什么你会觉得值？
2. 10 分是随时能开口讲，1 分是完全讲不出来 —— 你现在几分？**为什么不是更低？**
3. 哪一个瞬间让你觉得「就是它了」？
4. 用一句话说，你是做什么的？
5. 接下来 30 天，你做哪一件事？

## 适用对象

问题库按五类对象设计了替换词：

| 类型 | 典型画像 | 最易卡住的层 |
|---|---|---|
| **A 创业者** | 有产品、有客户、讲不清 | 战略层 |
| **B 专业人士** | 医生 / 律师 / 教师 / 工程师 | 叙事层（身份冲突） |
| **C 职场人** | 想做副业 / 转型 | 事实层（挖不出素材） |
| **D 素人** | 无标签、自我怀疑 | 意义层（最深） |
| **E 内容创作者** | 有流量无变现 / 有内容无定位 | 战略层 |

## 方法论来源

- 一场真实的 90 分钟 IP 访谈逐字稿的完整拆解（提问链、命名时机、裁决方式、时间配比）
- 教练技术体系：**Dilts 逻辑层次**、**ORID 焦点讨论法**、**GROW**（补全了原版缺失的 W 环节）、刻度化提问、奇迹问题、例外提问、动机式访谈
- 原访谈中被识别出的六个结构缺陷，在本技能中已全部修正：无合约、无刻度化、无承诺环节、情绪被概念覆盖、裁决无替代方案、只给方向不给做法

---

## 十条硬性纪律（违反即失效）

1. 一次只问一个问题
2. 形容词必须换成数字
3. 不许替对方回答
4. 裁决必须配替代方案
5. 复述用他的词，不用你的词
6. 每 15-20 个问题命名一次
7. 自我暴露 ≤ 2 次、每次 ≤ 30 秒
8. 不许跳层
9. 心理障碍优先于技巧
10. **必须有承诺环节** —— 没有"什么时候做、怎么验收"，这场对话等于没发生
